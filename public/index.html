Job Broadcast (NIP-90)

KIND 5000 • NOSTR MESH
02

Blinded Ecash Escrow

Client computes BDHKE blinded point B_ = Y + r*G and attaches off-chain Cashu tokens. Mint verifies funds without learning client identity.

NUT-00 BDHKE • BLIND SATS
03

Confidential AI Inference

DVM worker receives job, atomically swaps token proofs via NUT-03, executes local LLM inference in volatile memory, and wipes prompt.

LOCAL ENGINE • RAM ONLY

NIP-44 Result Delivery

Result is encrypted with authenticated ChaCha20-Poly1305 and published as Kind 6000 back to relays. Only the client can decrypt.
