Relay Race Mitigation & Deduplication Engine

When a user broadcasts a Kind 5000 request, multiple public relays receive and forward it simultaneously. PrivaVend implements an in-memory LRU Bloom-Deduplication Cache. The first event received acquires an atomic settlement lock; identical event IDs arriving from alternate relays within the 10,000-event window are discarded with 0ms overhead, preventing duplicate AI execution.

Blind Diffie-Hellman Key Exchange (NUT-00 BDHKE)

Cashu achieves unconditional sender anonymity through Chaumian blind signatures over the Secp256k1 elliptic curve. The mathematical mechanics:

Stage 1: Blinding by Client

1. Client picks random secret \(x\) and blinding scalar \(r \in [1, n-1]\).

2. Computes curve point: \(Y = \text{hash\_to\_curve}(x)\).

3. Blinds the point: \(B' = Y + rG\).

Client sends blinded point \(B'\) to Mint.

Stage 2: Blind Signature by Mint

1. Mint holds private key \(k\), public key \(K = kG\).

2. Signs blinded point without seeing secret \(x\):

\(C' = k \cdot B' = k(Y + rG) = kY + krG\)

Mint returns blind signature \(C'\) to Client.

Stage 3: Unblinding by Client

Client subtracts blinding factor using Mint's public key \(K\):

\(C = C' - rK = (kY + rkG) - rkG = kY\)

Client now holds valid proof \((x, C)\).

Stage 4: PrivaVend Settlement Swap (NUT-03)

PrivaVend receives \((x, C)\) from Nostr requester.

Mint verifies \(C == k \cdot \text{hash\_to\_curve}(x)\) and swaps it for fresh daemon-blinded proofs.

Settled atomically off-chain before AI inference starts!
